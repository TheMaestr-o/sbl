# Аудио уроков

Страница находит части сама. Ничего склеивать и нигде прописывать не нужно —
достаточно положить файлы сюда с правильными именами.

## Имена файлов

```
{язык}-{номер урока}-{часть}.mp3
```

| Файл | Что это |
|---|---|
| `de-09-0.mp3` | вступление: номер и тема урока, памятный стих, вводная цитата |
| `de-09-1a.mp3` | воскресенье, вопрос **a** |
| `de-09-1b.mp3` | воскресенье, вопрос **b** |
| `de-09-2a.mp3` | понедельник, вопрос **a** |
| … | … |
| `de-09-7a.mp3` | суббота |

Цифра — день: **1** воскресенье … **7** суббота. Буква — вопрос, от `a` до `h`.
Номер урока всегда двумя цифрами: `09`, не `9`. Язык — `de`, `en` или `ru`.

Сколько вопросов в дне, столько файлов. Страница перебирает буквы по порядку и
останавливается на первой отсутствующей, поэтому пропусков в середине быть не
должно: если есть `1a` и `1c`, но нет `1b` — `1c` не найдётся.

Нет файла `-0.mp3` — плеера не будет вовсе. Так квартал без записей ничего не
обещает и не показывает мёртвую кнопку.

## Шаблон для ElevenLabs

Названия дорожек берутся из самого урока, поэтому в текст их писать не нужно —
только то, что должно прозвучать.

### Блок 1 — вступление (`-0.mp3`)

```
[calm] [Номер] Lektion. [Название темы урока].
<break time="1.0s"/>
Leittext aus [Книга, Kapitel …, Vers … — словами]:
<break time="0.5s"/>
„[Текст памятного стиха]“
<break time="1.0s"/>
Aus dem Buch „[Название книги Духа пророчества]“, Seite [Номер страницы]:
<break time="0.5s"/>
„[Текст цитаты]“
```

### Блок 2 — вопрос (`-1a.mp3`, `-1b.mp3`, `-2a.mp3` …)

```
[clear] [Номер и название раздела, если есть].
<break time="0.5s"/>
Frage [a/b/c]: [Текст вопроса из урока]
<break time="0.5s"/>
[Книга, Kapitel …, Vers … — словами]:
<break time="0.5s"/>
„[Текст библейского стиха]“
<break time="1.0s"/>
Aus dem Buch „[Название книги]“, Seite [Номер страницы]:
<break time="0.5s"/>
„[Текст цитаты из Духа пророчества]“
```

Название раздела произносится один раз — в первом вопросе дня. У следующих
вопросов того же дня строку `[clear] [Номер и название раздела]` можно опустить.

Ссылка на Писание стоит своей строкой и называется целиком, словами:
`Zweiter Korinther, Kapitel zwei, die Verse vierzehn und fünfzehn`. Ни цифр, ни
сокращений — их голос не прочтёт. Подробнее — в скилле `sbl-audio`.

## Как добавить запись руками

Один блок текста — один файл. Порядок такой:

**1. Взять текст блока.** Либо скилл `sbl-audio` («подготовь 4 блок 9 урока на
немецком»), либо самому по шаблонам выше.

**2. Озвучить.** Вставить блок в ElevenLabs целиком, вместе с метками `[calm]`,
`[clear]` и `<break …/>` — это указания голосу, читать их он не будет.
Сгенерировать, скачать.

> Голос и его настройки держать **одни и те же на весь урок**. Части идут подряд
> одна за другой, и смена голоса посреди урока слышна сразу.

**3. Положить на место.** Файл скачался с именем вроде
`ElevenLabs_2026-08-25T20_44_40_JM - Husky…_v3.mp3`. Его нужно переименовать в
`de-09-1b.mp3` и положить в `audio/`. Руками — просто переименовать и
перетащить. Или помощником, он же сразу скажет, что вышло:

```bash
cd ~/Developer/sbl
python3 tools/audio-add.py ~/Downloads/ElevenLabs_2026-08-25T20_44_40*.mp3 de-09-1b
```

Помощник не даст ошибиться в имени (`de-9-1b` — уже отказ, урок пишется двумя
цифрами), не перепишет молча то, что уже лежит, и после переноса покажет, что
в этом уроке есть и нет ли пропусков.

**4. Проверить порядок.** В любой момент:

```bash
python3 tools/audio-add.py --check de 9
```

```
de, урок 09:
  0   вступление
  1  воскресенье  a b
  2  понедельник  a b c
  дыр нет — плеер соберёт всё подряд
```

Две вещи, на которые он ругается, и обе ломают плеер: **нет `-0.mp3`** — плеера
не будет вовсе; **пропуск в буквах** — всё, что после дыры, не найдётся.

**5. Выложить.**

```bash
git add audio && git commit -m "audio" && git push
```

**6. Посмотреть.** Через минуту-две GitHub Pages пересоберётся, и часть появится
в плеере сама — ни прописывать её где-то, ни перечислять не нужно. До пуша то же
самое видно локально: страница берёт файлы из `audio/` рядом с собой.

Названия дорожек в плеере берутся из самого урока — раздел дня и буква вопроса.
Поэтому в озвучиваемый текст их писать не надо, только то, что должно прозвучать.
