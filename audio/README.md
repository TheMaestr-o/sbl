# Аудио уроков

Страница находит части сама. Ничего склеивать и нигде прописывать не нужно —
достаточно положить файлы сюда с правильными именами.

## Имена файлов

```
{язык}-{номер урока}-{часть}.mp3
```

| Файл | Что это |
|---|---|
| `de-09-0.mp3` | вступление: номер и тема урока, памятный стих, вводная цитата |
| `de-09-1a.mp3` | воскресенье, вопрос **a** |
| `de-09-1b.mp3` | воскресенье, вопрос **b** |
| `de-09-2a.mp3` | понедельник, вопрос **a** |
| … | … |
| `de-09-7a.mp3` | суббота |

Цифра — день: **1** воскресенье … **7** суббота. Буква — вопрос, от `a` до `h`.
Номер урока всегда двумя цифрами: `09`, не `9`. Язык — `de`, `en` или `ru`.

Сколько вопросов в дне, столько файлов. Страница перебирает буквы по порядку и
останавливается на первой отсутствующей, поэтому пропусков в середине быть не
должно: если есть `1a` и `1c`, но нет `1b` — `1c` не найдётся.

Нет файла `-0.mp3` — плеера не будет вовсе. Так квартал без записей ничего не
обещает и не показывает мёртвую кнопку.

## Шаблон для ElevenLabs

Названия дорожек берутся из самого урока, поэтому в текст их писать не нужно —
только то, что должно прозвучать.

### Блок 1 — вступление (`-0.mp3`)

```
[calm] [Номер] Lektion. [Название темы урока].
<break time="1.0s"/>
Leittext aus [Книга, Kapitel …, Vers … — словами]:
<break time="0.5s"/>
„[Текст памятного стиха]“
<break time="1.0s"/>
Aus dem Buch „[Название книги Духа пророчества]“, Seite [Номер страницы]:
<break time="0.5s"/>
„[Текст цитаты]“
```

### Блок 2 — вопрос (`-1a.mp3`, `-1b.mp3`, `-2a.mp3` …)

```
[clear] [Номер и название раздела, если есть].
<break time="0.5s"/>
Frage [a/b/c]: [Текст вопроса из урока]
<break time="0.5s"/>
[Книга, Kapitel …, Vers … — словами]:
<break time="0.5s"/>
„[Текст библейского стиха]“
<break time="1.0s"/>
Aus dem Buch „[Название книги]“, Seite [Номер страницы]:
<break time="0.5s"/>
„[Текст цитаты из Духа пророчества]“
```

Название раздела произносится один раз — в первом вопросе дня. У следующих
вопросов того же дня строку `[clear] [Номер и название раздела]` можно опустить.

Ссылка на Писание стоит своей строкой и называется целиком, словами:
`Zweiter Korinther, Kapitel zwei, die Verse vierzehn und fünfzehn`. Ни цифр, ни
сокращений — их голос не прочтёт. Подробнее — в скилле `sbl-audio`.

## Как выложить

```bash
cd ~/Developer/sbl
git add audio && git commit -m "audio" && git push
```

Через минуту-две GitHub Pages пересоберёт страницу, и части появятся в плеере.
