# Черновики боковой панели

Здесь лежит то, из чего выросла панель с оглавлением квартала (`#outline` в
`index.html`). Ничего из этого страница не грузит — это материал, а не код.

| Файл | Что это |
|---|---|
| `sbloutline.css` | стили страницы-источника, `sbl.sdarm.org/study/de/2026-3/outline`, снятые как есть |
| `sbloutline-test.html` | сама страница-источник, сохранённая целиком |
| `sbloutlinedemo.html` | проба стилей: как список квартала мог бы выглядеть |
| `sbloutline-preview.html` | проба поведения: панель, которая выезжает и уезжает |

Лежали в корне рядом с продуктом; перенесены сюда, чтобы корень был корнем.
