# MANNA — Sabbath Bible Lesson (print edition)

The weekly **Sabbath Bible Lesson** in the original printed-booklet layout, as one clean page you can read on screen or **save as PDF**. Single language at a time — **DE · EN · RU** — no side‑by‑side reading.

**Live:** https://themaestr-o.github.io/manna-print/

## Features
- Faithful booklet layout (title band, memory‑verse box, section bands, day tags) built as pure CSS — scales without loss.
- **‹ ›** navigate week by week; tap the label to jump to today.
- **DE · EN · RU** language switch.
- **Verses on/off** — show the full Bible text under each reference (KJV / Luther / Синодальный), pulled live from SDARM.
- **↓ PDF** — opens the print dialog; choose *Save as PDF*. For a clean file, turn **off** “Headers and footers” in the dialog.
- Works offline after first load (service worker caches the lesson and Bible data).
