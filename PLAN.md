## Часть A. PDF — что чинить

### A1. `<html lang="en">` намертво зашит → русский и немецкий переносятся неправильно
**Проверено.** [index.html:2](index.html#L2) — язык документа никогда не меняется, а весь
текст свёрстан по ширине с `hyphens:auto` ([:155](index.html#L155), [:161](index.html#L161),
[:181](index.html#L181), [:196](index.html#L196), [:197](index.html#L197)).
Chrome берёт словарь переносов по языку документа. При `lang="en"` кириллица не
переносится **вообще** → в выключке зияющие дыры между словами (видно на 1-й стр. RU-PDF:
«Внутренний мир – вот, что вам нужно…»), а немецкий рвётся по английским правилам.

Пересобрал тот же PDF с `<html lang="ru">` — переносы появились («Жаж-дете»,
«уподо-биться», «обладате-лем»), реки исчезли, абзацы стали плотными.

**Фикс:** одна строка в `render()` — `document.documentElement.lang = lang;`
**Цена:** 5 минут. **Эффект:** самый заметный из всего списка. Делать первым.

### A2. Печать стартует по таймеру, а не по готовности шрифтов
[index.html:707](index.html#L707) — `setTimeout(…, 120)` и сразу `window.print()`.
Если PT Serif/PT Sans ещё не дошли (медленная сеть, первый визит, квартал на 123 стр.),
PDF уходит в Georgia/системный — другие метрики, другая разбивка на страницы.

**Фикс:** `await document.fonts.ready` + двойной `requestAnimationFrame`, потом печать.

### A3. Офлайн PDF выходит не тем шрифтом
[sw.js:15-49](sw.js#L15-L49) — service worker кэширует только свой origin и `app.sdarm.org`.
`fonts.googleapis.com` / `fonts.gstatic.com` мимо кэша → офлайн шрифтов нет, а README
обещает «works offline». Буклет офлайн печатается чужой гарнитурой.

**Фикс:** либо положить 4 woff2 в репо и подключить через `@font-face` локально (надёжнее
и быстрее), либо добавить домены шрифтов в cache-first ветку SW. Я за локальные файлы —
заодно уходит preconnect к Google и страница грузится быстрее.

### A4. Не задан формат листа
В `@page` ([:275](index.html#L275)) есть `margin:15mm`, но нет `size`. У кого в системе
Letter — вёрстка едет: посадочное место «плашки LESSON» задано в px
(`.top{padding-right:292px}`), а ширина листа другая.

**Фикс:** `@page{ size: A4; }` — буклет и есть A4.

### A5. После сохранения квартала страница остаётся в режиме квартала
[index.html:702-708](index.html#L702-L708) — `savePdf()` переключает `scope` и не
возвращает обратно. Человек сохранил квартал, а на экране остались 13 уроков и
подпись квартала вместо номера урока; вернуться можно только через календарь.

**Фикс:** запомнить прежний `scope`, вернуть по `afterprint`. И показывать активный
режим на кнопках, раз он влияет на экран.

### A6. Имя файла PDF — «SBL Edition — Sabbath Bible Lesson»
Браузер берёт имя из `<title>`. Все сохранённые уроки в папке называются одинаково.

**Фикс:** на время печати подменять `document.title` на `SBL 2026-Q3-06 Вера и принятие`
(или `SBL 2026-Q3 весь квартал`), по `afterprint` возвращать.

### A7. `dropPageNo` не ловит номер, прилипший без пробела
**Проверено на данных.** [index.html:454-461](index.html#L454-L461) требует `\s+` перед
цифрами. В PDF квартала, стр. 10: *«5. Опишите величайший дар Христа для нас.14»* —
`14` это номер страницы буклета, он остался в тексте.

```
"…для нас.14"   → "…для нас.14"    ← мимо
"…для нас. 14"  → "…для нас."      ← ловится
```
**Фикс:** сделать пробел необязательным после точки: `/^([\s\S]*?[.!?])\s*(\d{1,3})\s*$/`,
защиту от диапазона страниц («С.442. 443») оставить как есть.

### A8. Абзац комментария разорван посреди фразы
В данных длинная цитата иногда приходит двумя `note`-элементами, и разрыв попадает в
середину предложения: «…Согрешив, сыны человеческие» / «стали подданными сатаны.»
([index.html:507](index.html#L507) рисует их как два абзаца с отбивкой).

**Фикс:** при сборке склеивать соседние `note`, если предыдущий не оканчивается на
`.!?…»"` — тогда это один абзац, а не два.

### A9. Мелочи типографики (заодно)
- В русских данных попадаются прямые кавычки `"сыны Божьи"` вместо «ёлочек» — нормализовать
  рядом с `strip()`/`esc()` ([:368-370](index.html#L368-L370)).
- Дефис подменён минусом: «по−еврейски».
- Продолжение группы стихов на новой странице идёт без заголовка ссылки — добавить
  повтор ссылки с пометкой «(продолж.)».
- Для квартала: титульный лист + оглавление на 13 уроков (сейчас 123 страницы без
  единой навигации). `string-set` для колонтитула с названием урока в Chromium может не
  работать — проверить, иначе номер урока в подвал через `counter`.

**Порядок:** A1 → A2 → A4 → A5 → A6 → A7 → A3 → A8 → A9.
A1-A2-A4 дают 90% видимого улучшения и делаются за один вечер.

## Шаг 0 (без него не живёт ни одна фича выделения)

DOM пересобирается на каждый `render()`, поэтому привязывать пометки к узлам нельзя.
Нужны **устойчивые ключи**: при отрисовке каждому блоку выдаётся `data-k` вида
`d3.s2.note1` (день → подраздел → тип и номер), а пометка хранится как
`{lesson: "20260808", lang: "ru", k: "d3.s2.note1", from: 120, to: 168}` — смещения в
символах текста блока. Тогда пометки переживают перерисовку, смену размера шрифта,
включение стихов и — при желании — смену языка.

Хранилище: `localStorage["sbl.marks"]` (одна JSON-карта, урок → массив). Объём мизерный.

## Часть B. Десять решений: выделение и вставка текста

Помечено: **[БЕРУ]** — делаю в первую очередь, **[потом]** — вторая волна,
**[спорно]** — красиво, но не под этот проект.

### 1. Маркер по выделению — **[БЕРУ]**
Выделил текст → всплывает мини-панель у выделения → 4 цвета (жёлтый, зелёный, розовый,
голубой) + ластик. Ровно как маркером по бумажному буклету. Печатается в PDF —
`print-color-adjust:exact` уже стоит глобально ([:20](index.html#L20)), фон отрисуется.
Это ядро; пункты 2, 3, 9, 10 — надстройки над ним.

### 2. Второй ряд стилей: подчёркивание, волна, рамка — **[БЕРУ]**
Тот же тулбар, второй ряд. Нужен не для красоты: на ч/б принтере четыре цвета маркера
станут четырьмя одинаковыми серыми плашками. Подчёркивание и волна различимы всегда.
Плюс режим печати «пометки чёрно-белым» в настройках.

### 3. Заметка на полях — **[БЕРУ]**
Выделил → «заметка» → в тексте появляется маленький номерок, сама заметка живёт на правом
поле листа (на экране) и уходит сноской вниз страницы в PDF. Это то, чем буклет живёт в
классе: своя мысль напротив нужной строки.

### 4. Поле для своего ответа под вопросом + линейки для руки — **[БЕРУ]**
Под каждым «а./б.» разворачивается поле — записал ответ, он сохранился и печатается.
И зеркальная вещь для бумаги: режим «печатать пустые линейки под каждым вопросом» —
ради этого люди и печатают урок. Одна галочка в настройках, две строки в print-CSS.

### 5. Копировать со ссылкой — **[БЕРУ]**
Выделил текст стиха → «копировать» кладёт в буфер не голый текст, а
`«Если исповедуем грехи наши…» (1 Иоанна 1:9, Синодальный)`. Три формата на выбор:
обычный текст / markdown-цитата / для мессенджера. Плюс «скопировать урок целиком».
Дёшево, а пользуются каждый день.

### 6. Вставка стиха по ссылке прямо в заметку — **[БЕРУ]**
Пишешь в своей заметке `Ин 3:16` — оно разворачивается в текст стиха. Библия **уже**
загружена в приложение ([index.html:393-413](index.html#L393-L413)), парсер ссылок есть,
работает офлайн, ничего доставать не надо. Самая дешёвая «вау»-функция в списке.

### 7. Живые ссылки на стихи в тексте вопросов — **[потом]**
Автолинковка ссылок прямо в вопросах и комментариях: клик по «Иоанна 5:1-9» → поповер с
текстом, без включения общего режима стихов. Упирается в надёжный парсер ссылок для трёх
языков (сокращения книг в DE/EN/RU разные) — отдельная работа на пару дней.
В `sub.q[].sOsis` ссылки уже размечены, но только у вопросов, не внутри комментариев.

### 8. Поиск по выделению — **[потом]**
Выделил слово → «найти»: по уроку, по кварталу, по всей Библии. Данные локальные, поиск
мгновенный. Полезно, но это уже другой продукт — читалка, а не набор буклета.

### 9. «Мои пометки» отдельным разделом в PDF + экспорт/импорт — **[БЕРУ]**
В конце урока (или квартала) — сводка: все выделения, заметки и ответы со ссылкой на
раздел. Можно печатать только её — готовый конспект для класса на одном листе.
Плюс экспорт/импорт JSON, чтобы перенести пометки на другое устройство (синхронизации
нет и не надо, файл решает).

### 10. Ссылка на место в уроке — **[спорно]**
Выделил → «поделиться» → ссылка вида `#20260808/ru/d3.s2.note1:120-168`, которая
открывает урок, прокручивает и подсвечивает фрагмент. Красиво, но пока непонятно, кто
этим будет пользоваться — соседняя фича «картинка-карточка со стихом для мессенджера»
полезнее, а это уже другой жанр.

**Не вошло, но записываю:** режим учителя — вставка своего блока (вопрос, иллюстрация,
цитата) между вопросами урока, своим цветом, с печатью в PDF. Логично после пунктов 3-4,
на том же движке ключей.

## Часть B-bis. Что уже встроено в проект (2026-08-03, не закоммичено)

**Шаг 0 — ключи блоков. СДЕЛАНО.** Каждый блок текста получает `data-k`, не зависящий
от порядка элементов: `mem`, `qt`, `d0`, `d2s1q`, `d2s1v0`, `d2s1n0`, `d0r3`. Лист несёт
`data-les` и `data-lang`. Пометка хранится как ключ блока + смещения в символах, поэтому
переживает перерисовку, размер шрифта и включение стихов. Хранилище — `localStorage`
(`sbl.pencil`), отдельная запись на язык и урок.

**Решения 1, 2, 5 (маркер, стили, копирование). СДЕЛАНО.** Основной маркер — косой
мазок (плато плотности, хвостики только на настоящих краях выделения — грязного шва в
середине больше нет), плюс текстура пера, линия-ручка, волна и тонкие ручные фигуры
(обвести, рамка, зачеркнуть). Любой цвет, последние пять — в панели, инструмент
запоминается. Наложение краски через `multiply` сохраняется цепочкой.

**Решения 3, 4 частично (свой текст). СДЕЛАНО.** Заметка после любого блока и вставка
внутрь строки: синим, другой гарнитурой, с меткой «Моя заметка · дата» снизу и подсказкой.
В PDF печатается легенда «Синим — заметки и вставки читателя», на языке урока.

**Своё выделение вместо системного.** После отпускания мыши системное выделение
снимается, вместо него — свой призрак в цвете маркера: браузеру нечего подсвечивать и
его меню не всплывает поверх панели. Панель садится под выделением.

**Языки.** Все подписи инструмента (метка заметки, подсказка, легенда, тултипы, строка
«Пометки» в настройках) идут на языке урока — DE/EN/RU.

Проверено автотестом в headless Chrome: 4 пометки + вставка + заметка сохраняются,
`mkRestore()` идемпотентен (повторный вызов не удваивает), переключение EN → RU → EN
не смешивает пометки (ключи `en/20260808`, `ru/20260808`), всё доходит до PDF —
фигуры попадают в файл векторами.

Осталось: тач-жесты (сейчас только мышь), «Мои пометки» сводкой в PDF (решение 9),
экспорт/импорт JSON.

## Часть C. Что ещё нужно человеку, который изучает урок

Отсортировано по отношению «польза / цена», с учётом того, что **данные уже в
приложении**: урок разбит по дням (`dailyLessons`), три Библии целиком, всё офлайн.

### C1. Сегодняшний день, а не весь урок — **[БЕРУ]**
Урок расписан на семь дней, а страница вываливает все семь сразу. Открыл в среду —
показывается среда, остальное свёрнуто. Внизу семь точек: пройденные закрашены.
Это меняет привычку: не «прочитать урок в пятницу вечером», а каждый день понемногу.
Данные для этого уже есть, работы на день.

### C2. Режим самопроверки — **[БЕРУ]**
Переключатель: комментарии скрыты, остались вопрос и ссылка на стих. Сначала ответь
сам — потом раскрой. Сейчас страница даёт ответ раньше, чем человек успел подумать,
и урок читается, а не изучается. Одна кнопка, класс пользы.

### C3. Памятный стих в карточки с повторением — **[БЕРУ]**
Памятный стих недели → карточка, повторение по интервалам (FSRS — тот же движок, что
в english-bot). За квартал человек знает 13 стихов наизусть, а не «где-то читал».
Хранение локальное, сервер не нужен.

### C4. Раздатка для класса — **[БЕРУ]**
Третий вариант PDF рядом с «неделя / квартал»: только вопросы, ссылки и пустые линейки,
без комментариев. Тому, кто ведёт субботнюю школу, это нужно каждую неделю, а сейчас
он это делает руками в Word.

### C5. Стих в трёх переводах по клику — **[БЕРУ]**
Лютер, KJV и Синодальный уже загружены. Клик по ссылке → стих в трёх языках рядом.
Для двуязычных общин (а это половина аудитории) — сильнее любой другой фичи.

### C6. Глава целиком из ссылки — **[БЕРУ]**
От стиха открыть всю главу с подсветкой цитируемых стихов: «а что там дальше?» —
самый частый вопрос при изучении. Данные локальные, поповер поверх страницы.

### C7. Слушать урок — **[потом]**
Web Speech API читает комментарий и стихи; в macOS/iOS голоса приличные и офлайн.
Для дороги и для тех, кому тяжело читать. Разными голосами: вопрос — один, стих — другой.

### C8. Поиск по кварталу и по Библии — **[потом]**
«Где в этом квартале про молитву?» Данные локальные, ищется мгновенно. Пересекается
с решением 8 из части B — делать заодно.

### C9. Карточка памятного стиха картинкой — **[потом]**
Canvas рисует стих на фоне в стиле буклета → PNG для группы в мессенджере. Дёшево,
и это единственный способ, которым страница расходится дальше своей аудитории.

### C10. Печать брошюрой — **[спорно]**
Две страницы на лист со спуском полос, чтобы сложить и сшить настоящий буклет.
Красиво звучит, но спуск полос средствами CSS ненадёжен; проще подсказка в диалоге
печати «2 страницы на лист, брошюра».
